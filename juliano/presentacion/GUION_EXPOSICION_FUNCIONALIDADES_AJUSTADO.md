# Guion ajustado de exposición de BaseAccess


## Diapositiva 1. BaseAccess

Buenos días. Presentaré BaseAccess, una herramienta creada para registrar
documentos, consultar su información y mantener seguimiento de sus movimientos.

## Diapositiva 2. ¿De qué se trata?

BaseAccess reúne las tareas de registro, consulta y seguimiento documental. Su
finalidad es simplificar el trabajo diario, evitar que una misma información se
escriba varias veces y facilitar actividades que anteriormente exigían escribir manualmente.

## Diapositiva 3. Menú de inicio

El menú de inicio muestra el módulo seleccionado, la lista de documentos y las
acciones principales. Desde esta pantalla se puede consultar, abrir o modificar
un registro.

## Diapositiva 4. Diseño y facilidad de uso

El programa utiliza formas definidas, colores contrastantes y opciones fáciles
de reconocer. También ofrece una apariencia con accesibilidad, navegación sencilla,
respaldo de la información y portabilidad total.

## Diapositiva 5. Todo el control documental en un solo lugar

Las acciones generales, los módulos y la búsqueda están reunidas
en la pantalla principal. Esta organización permite registrar, localizar y
gestionar información sin recorrer varias pantallas.

**Clip: 6,6 segundos.**



Esta opción permite cambiar el orden de las secciones inferiores y colocar
primero las que se utilizan con mayor frecuencia.

## Diapositiva 7. Zoom en las tablas

**Clip: 12,4 segundos.**



Las tablas pueden acercarse o alejarse para facilitar su lectura. Al aumentar
el tamaño, aparece una barra para recorrer todas las columnas. Al pulsar el
porcentaje, la vista vuelve a la normalidad.

## Diapositiva 8. Manual integrado y temas visuales

**Clip: 29,5 segundos.**

Es posible alternar entre una presentación clara y una oscura, de modo que cada persona pueda elegir la apariencia más cómoda según la iluminación del lugar o sus preferencias de lectura. Como podemos observar, el cambio se aplica inmediatamente en toda la interfaz, sin modificar la información almacenada.

Además, BaseAccess incorpora un manual que puede consultarse sin salir de la aplicación. En él se explican las funciones disponibles y los procedimientos necesarios para utilizar cada herramienta. Esto permite resolver dudas rápidamente mientras se trabaja y facilita el aprendizaje de quienes utilizan el programa por primera vez.

las coincidencias. Así se localiza un documento sin revisar manualmente toda la

## Diapositiva 15. Movimientos documentales

**Clip: 41,3 segundos.**



El historial conserva los cambios realizados en cada documento. Esta vista
permite observar cómo se encontraba cada dato durante las distintas etapas e
identificar qué información fue modificada para comparar el estado actual con los
anteriores. Su consulta no altera el registro; solamente muestra su evolución

Esta es la trazabilidad deseada en el programa, no tenemos registros antiguos a simple vista, pero podemos acceder a ellos cuando haga falta

## Diapositiva 16. Duplicar elementos y exportar a Excel

**Clip: 60 segundos.**


La opción de duplicar permite crear un registro nuevo tomando como base otro que contiene información semejante. Una vez generada la copia, podemos modificar los campos que sean diferentes antes de guardarla. Esta función resulta especialmente útil cuando se deben registrar varios documentos relacionados, porque evita escribir nuevamente todos los datos y reduce el tiempo empleado en el proceso.

BaseAccess también permite exportar la información a Excel. Antes de generar el archivo, podemos seleccionar el módulo que deseamos consultar, escoger las columnas que aparecerán y establecer las condiciones que deben cumplir los registros. De esta manera, el archivo no tiene que incluir toda la información almacenada, sino solamente los datos necesarios para una consulta o revisión determinada.

En este ejemplo aplicamos un filtro por estatus. Después de completar la exportación, podemos observar que el archivo de Excel contiene únicamente el registro que cumple con la condición seleccionada.

BaseAccess incluye una calculadora diseñada para apoyar las operaciones que pueden surgir durante el manejo de la información. ## Diapositiva 18. Creación de hojas para otros años

**Clip: 83 segundos.**



El programa permite crear hojas independientes para organizar la información correspondiente a distintos años o períodos de trabajo. Antes de crear una nueva, observemos los registros y las validaciones disponibles actualmente en cada módulo.

Para comenzar, seleccionamos la opción de crear una hoja, le asignamos un nombre que permita identificarla con facilidad y decidimos si deseamos copiar las validaciones existentes. Estas validaciones corresponden a las opciones predeterminadas que aparecen en algunos campos de los formularios y pueden conservarse para evitar configurarlas nuevamente.

La nueva hoja comienza completamente vacía, es decir, sin documentos registrados, pero puede mantener las validaciones de la hoja utilizada como referencia. Esto facilita la preparación de un nuevo período sin trasladar documentos que pertenecen al año anterior.

Cada hoja administra su información de manera independiente. Por esta razón, crear, editar o eliminar una validación dentro de una hoja no altera las configuraciones de las demás. Lo mismo sucede con los documentos: cualquier registro creado, modificado o eliminado afecta únicamente a la hoja que se encuentra activa en ese momento.

Esta separación permite comenzar un nuevo año con una estructura conocida, manteniendo organizada la información y evitando que se mezclen documentos de períodos diferentes. Finalmente, desde las opciones disponibles también podemos cambiar el nombre de una hoja o eliminarla cuando ya no sea necesaria.


## Diapositiva 19. Ruta de Procesos

**Clip: 125 segundos.**



Ruta de Procesos es una herramienta que permite representar visualmente el avance de las actividades a lo largo del tiempo.

La información se organiza primero mediante hojas. Cada hoja funciona de manera independiente y puede contener varias juntas, lo que permite mantener separados los asuntos correspondientes a diferentes períodos o reuniones. Como podemos observar, dentro de una junta se pueden incorporar semanas y procesos según las necesidades del seguimiento.

Cada semana presenta los días que la componen, mientras que cada proceso ocupa una fila de la tabla. El cruce entre la fila de un proceso y la columna correspondiente a un día forma una casilla. En esa casilla se registra la actividad realizada durante esa fecha. De esta forma, al recorrer una fila horizontalmente, podemos observar cómo avanzó un proceso con el paso de los días.

Las actividades se identifican mediante leyendas. Cada leyenda posee un nombre y un color, los cuales sirven para representar una etapa, una condición o una actividad determinada. Gracias a esta diferenciación visual, es posible reconocer rápidamente el estado de un proceso sin tener que abrir cada casilla individualmente.

Una misma casilla también puede contener varias actividades cuando durante un día ocurrieron diferentes acciones relacionadas con el proceso. Esto permite conservar un seguimiento más completo y evita perder información importante acerca de lo realizado.

Para agilizar el trabajo, BaseAccess incluye una opción de selección múltiple. Con ella podemos marcar varias casillas, incluso si corresponden a días diferentes, y aplicarles una misma leyenda en una sola acción. Antes de guardar el cambio, el programa indica la cantidad de días seleccionados, permitiendo comprobar el alcance de la modificación antes de confirmarla.

También podemos desplazarnos entre las semanas para consultar actividades anteriores o continuar incorporando información en fechas posteriores. Cada actualización permanece asociada con la hoja y la junta donde fue realizada.
